# Монгол Бөх - 64 Bracket

Next.js + TypeScript + MongoDB ашигласан үндэсний 64 бөхийн bracket систем.

## Онцлог

- 64 бөхийн мэдээлэл (нэр, цол, зураг, аймаг) MongoDB-д хадгална
- Bracket үүсгэхдээ **даваа бүрийн учрааг гараар** оруулна
- Даваа дууссаны дараа **давсан бөхүүдийн жагсаалт** гарна
- Дараагийн давааг тэр жагсаалтаас дахин гараар онооно
- Дууссан барилдааны түүх хадгалагдана

## Эхлүүлэх

```bash
npm install
```

`.env.local` файл үүсгэж MongoDB холболтоо оруулна:

```
MONGODB_URI=mongodb+srv://...
```

```bash
npm run dev
```

http://localhost:3000 нээнэ.

## Ашиглах дараалал

1. **64 тест бөх үүсгэх** - Нүүр хуудас дээрх товч
2. **Шинэ Bracket үүсгэх**
3. **1-р давааны 32 учрааг гараар тааруулах** (эсвэл "Санамсаргүй")
4. Ялагчдыг тэмдэглээд → **давсан бөхүүдийн жагсаалт** гарна
5. Дараагийн давааг тэр жагсаалтаас дахин гараар онооно
6. Финал хүртэл үргэлжлүүлнэ

## API

| Endpoint | Method | Тайлбар |
|----------|--------|---------|
| `/api/wrestlers` | GET, POST | Бөхүүд |
| `/api/brackets` | GET, POST | Bracket жагсаалт/үүсгэх |
| `/api/brackets/[id]` | GET, PATCH, DELETE | Bracket дэлгэрэнгүй |
| `/api/seed` | POST | 64 тест бөх үүсгэх |
